# Skill Maintenance

Maintaining your own skills in the AI era.

## The atrophy problem

"Forced to vibe code at work, programmers say their skills are deteriorating" (real headline, 2026). Skills that go unused decay. AI accelerates this by removing the daily reps.

## What atrophies first

- Debugging intuition
- Pattern recognition
- Understanding of WHY code works (not just that it works)
- Ability to spot subtle bugs

## Deliberate practice schedule

- **Weekly**: solve one problem manually, no AI. Algorithm, system design, or debugging exercise.
- **Monthly**: code review without AI assistance. Train your own judgment.
- **Quarterly**: build something small from scratch. No copilot, no autocomplete.

## Skills that INCREASE in value with AI

- Architecture & system design (AI does this poorly)
- Code review judgment (someone must review AI output)
- Debugging complex systems (AI investigates, you must UNDERSTAND)
- Security thinking (AI writes confident insecure code)
- Business context (knowing WHAT to build)
- Communication (explaining trade-offs to non-technical stakeholders)

## Skills that DECREASE in value

- Syntax memorization
- Boilerplate typing
- Language trivia
- Mechanical refactoring
- Documentation writing (first draft)

## Learning strategy

Focus on UNDERSTANDING over DOING. Read code more than you write. Study systems more than implementations.

## The "can I review this?" test

For any AI-generated code, ask: "could I have caught a bug in this?" If no, you have a skill gap — close it before you depend on it.

## Anti-patterns

- Never coding manually
- Outsourcing all thinking to AI
- Not understanding your own codebase
- Skipping fundamentals
