# AI-Era Career Strategy

## How AI Changes Engineering Roles

### Augmentation, Not Replacement
- AI handles boilerplate; engineers handle judgment
- The job shifts from "write code" to "define intent + verify output"
- More time on architecture, design, evaluation
- Less time on syntax, repetition, lookup
- Engineers who use AI well produce 2-5x more than those who don't
- The gap between "can code" and "can ship" widens

### New Responsibilities
- Evaluating AI-generated code for correctness and security
- Designing systems that are AI-friendly to maintain
- Writing specifications precise enough for AI to implement
- Building evaluation frameworks for AI outputs
- Understanding when AI is confident vs hallucinating

## Skills That Compound with AI

### System Thinking
- Seeing how components interact at scale
- Predicting failure modes and edge cases
- Designing for evolution and change
- Understanding organizational dynamics that shape systems

### Evaluation and Judgment
- Knowing when code is correct (testing, reasoning, invariants)
- Assessing tradeoffs that don't have clear answers
- Deciding what to build (product sense)
- Recognizing when AI output is subtly wrong

### Design
- API design that communicates intent
- Architecture that manages complexity
- Abstractions that simplify without hiding
- User experience that solves the right problem

### Communication
- Translating business needs into technical specifications
- Explaining technical decisions to non-technical stakeholders
- Writing clear requirements that reduce ambiguity
- Giving feedback that improves systems and people

## Skills That Depreciate

### Declining Value
- Memorizing syntax and APIs (AI recalls faster)
- Writing boilerplate and CRUD operations
- Manual code formatting and style enforcement
- Translating between languages mechanically
- Writing documentation for straightforward code

### Still Needed But Less
- Debugging simple errors (AI catches many)
- Writing tests for obvious paths (AI generates these well)
- Code review for style issues (linters + AI)
- Initial implementation of well-defined features

## Building an AI-Augmented Workflow

### Daily Practice
- Use AI for first drafts, then apply judgment
- Verify AI output the same way you'd review a junior's PR
- Build personal prompt libraries for recurring tasks
- Keep a log of when AI helps vs when it misleads

### Workflow Integration
- Spec writing: human defines intent, AI helps structure
- Implementation: AI drafts, human reviews and iterates
- Testing: AI generates cases, human validates coverage
- Documentation: AI drafts, human ensures accuracy

### Knowing When NOT to Use AI
- Security-critical code (trust but verify extra hard)
- Novel architecture decisions (AI optimizes for common patterns)
- Ambiguous requirements (AI will guess silently)
- When you need to deeply understand the code yourself

## Differentiating Yourself

### Judgment and Taste
- Knowing what to build matters more than building fast
- Saying no to features is a skill AI can't replace
- Understanding users requires empathy, not just data
- Making tradeoffs explicit requires wisdom

### Context and Relationships
- Understanding organizational politics and priorities
- Knowing which stakeholder to involve when
- Building trust through consistency and follow-through
- Navigating ambiguity with pragmatism

### Unique Combinations
- Domain expertise + engineering (fintech, healthtech, etc.)
- Technical depth + communication skills
- Systems thinking + business acumen
- AI literacy + specialized field knowledge

## AI Literacy as Table Stakes

### Core Competencies
- Prompt engineering: structured inputs, chain of thought, few-shot
- Evaluation: knowing when output is good/bad/dangerous
- Tool selection: which AI tool for which task
- Limitation awareness: hallucination, training cutoffs, context windows

### Building AI Intuition
- Use multiple AI tools -- notice where they differ
- Read AI research summaries (not papers -- summaries)
- Experiment with different prompting strategies
- Track success/failure patterns over time

### Staying Current
- Follow 3-5 credible AI researchers/practitioners
- Try new tools as they launch (low cost, high learning)
- Join communities where practitioners share workflows
- Focus on patterns, not specific tools (tools change fast)
