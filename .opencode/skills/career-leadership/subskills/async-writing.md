# Subskill: Async Writing

> Activate when: remote, distributed, timezone, written-first, documentation tooling, reduce meetings

Async-first communication is the default for distributed teams. The principle: **write once, read many.** Time spent writing clearly is repaid every time someone reads instead of interrupting you or scheduling a meeting.

## Principles

- **Write once, read many.** A clear doc scales; a hallway conversation reaches one person.
- **Topic sentence first**, supporting details below. The reader gets the point in one line and drills down only if needed.
- **Load context explicitly.** Assume the reader has NO shared context from hallway chats, standups, or your last thread. State what they need to understand this.
- **Optimize for the reader in another timezone** who can't ask a follow-up for 12 hours. If they'd have questions, answer them preemptively.

## Structure for Scannability

- Short paragraphs (2-4 sentences). Walls of text get skipped.
- Bullet points for lists and options.
- **Bold** key terms and decisions so skimmers catch them.
- Link to sources instead of pasting -- keeps content fresh and short.
- Put the ask / decision at the top, context below.

## Tooling (right tool per purpose)

| Purpose | Tool | Why |
|---------|------|-----|
| Proposals, technical discussion | GitHub Discussions | Threaded, versioned, links to code |
| Status, tasks, tracking | Linear / Jira | Structured, queryable state |
| Long-form docs, specs | Notion / Confluence | Searchable, durable, linkable |
| Ephemeral chatter | Slack | Fast, but NOT a system of record |

Rule: Slack is ephemeral only. Anything that matters in a week belongs in a durable, searchable place.

## Async Decision-Making

- **RFC with a deadline**: propose, set a review-by date, gather comments.
- **"Silence is consent"** -- but only with an explicit opt-out window: "If no objections by Thursday EOD, we proceed." State it clearly so silence is a real signal, not just people missing it.
- Tools like **Loomio** or a poll for structured group decisions.
- Escalate to a synchronous meeting ONLY when async rounds fail to converge.

## Anti-Patterns

- Burying the decision in paragraph 5 -> readers miss it.
- Assuming shared context -> the timezone-shifted reader is lost.
- Using Slack as the record of a decision -> it's gone in a week.
- "Silence is consent" with no stated deadline -> nobody knew they were agreeing.
- Scheduling a meeting to share information that could be a doc.
