# Sprint Goal Writer

## Format

> "By end of sprint, [user/stakeholder] can [measurable outcome]."

## Prompt Template

```
Given:
- Sprint number: ___
- Top priority backlog items: ___
- Product goal context: ___

Write a sprint goal that:
1. Describes ONE outcome (not a list of tasks)
2. Names who benefits
3. States what they can do (not what team builds)
4. Is verifiable in sprint review demo
```

## Quality Checklist

| Check | Pass? |
|-------|-------|
| Outcome-focused (not output/task list)? | |
| Single sentence? | |
| Measurable/demonstrable in sprint review? | |
| Achievable at 80% capacity (leave 20% buffer)? | |
| Stakeholder can understand without jargon? | |

## Anti-patterns

- "Complete stories X, Y, Z"  -  task list, not goal
- "Improve performance"  -  not measurable
- "Start working on auth"  -  no completion criteria
- Two goals joined with "and"  -  pick one or split sprint
