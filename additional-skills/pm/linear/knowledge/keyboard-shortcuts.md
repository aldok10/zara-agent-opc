# Keyboard Shortcuts

Essential Linear shortcuts. Memorize top 10, reference rest.

## Navigation

| Shortcut | Action |
|----------|--------|
| `Cmd+K` | Command palette (universal search) |
| `G then I` | Go to Inbox |
| `G then M` | Go to My Issues |
| `G then V` | Go to Views |
| `G then T` | Go to Team |
| `G then P` | Go to Projects |
| `G then C` | Go to Cycles |

## Issue Actions

| Shortcut | Action |
|----------|--------|
| `C` | Create new issue |
| `Enter` | Open selected issue |
| `Escape` | Close panel / go back |
| `S` | Set status |
| `P` | Set priority |
| `A` | Assign |
| `L` | Add label |
| `Shift+P` | Set project |
| `Shift+C` | Set cycle |
| `Cmd+Shift+.` | Add sub-issue |

## Bulk & Navigation

| Shortcut | Action |
|----------|--------|
| `X` | Select issue |
| `Shift+X` | Select range |
| `Cmd+A` | Select all visible |
| `J/K` | Move down/up in list |
| `D` | Set due date |
| `Cmd+D` | Duplicate issue |
| `Cmd+Backspace` | Delete issue |
| `Cmd+Shift+A` | Archive issue |
| `F` | Filter view |
| `Cmd+/` | Toggle sidebar |

## Asks

| Shortcut | Action |
|----------|--------|
| `G then A` | Go to Asks inbox |
| `Shift+A` | Convert ask to issue |
| `R` | Reply to ask |

## Initiatives

| Shortcut | Action |
|----------|--------|
| `G then N` | Go to Initiatives |
| `Enter` | Open initiative / drill into sub-initiative |
| `Shift+N` | Create new initiative |

## Cycles

| Shortcut | Action |
|----------|--------|
| `G then C` | Go to Cycles |
| `]` | Next cycle |
| `[` | Previous cycle |
| `Shift+C` | Assign issue to current cycle |

## Bulk Actions

| Shortcut | Action |
|----------|--------|
| `X` then `S` | Select → bulk set status |
| `X` then `A` | Select → bulk assign |
| `X` then `P` | Select → bulk set priority |
| `Cmd+Shift+L` | Bulk add label to selection |
| `Cmd+Backspace` | Bulk delete selected |

## Pro Tips

- `Cmd+K` then type team name → fastest team switch
- Select multiple → bulk status/priority/assign
- `Tab` in issue detail → cycle through fields
- `/` in description → slash commands (code, table, etc.)
- `Cmd+K` then "initiative" → jump to any initiative by name
- `G then A` → triage asks without leaving keyboard
