# Initiative Template

Structure Linear Initiatives for clarity and trackability.

## Format

```
Title: [Verb] + [Outcome] (e.g., "Reduce API p99 latency to <200ms")
Description: 1-2 sentences why it matters. Link strategy doc.
Target Date: YYYY-MM-DD | Owner: [team/person] | Health: onTrack|atRisk|offTrack
```

## Sub-Initiative Hierarchy (up to 5 levels)

```
L1: Company Goal (yearly)
  L2: Org Initiative (quarterly)
    L3: Team Initiative (6-8 weeks)
      L4: Project (Linear projects)
        L5: Milestone/deliverable
```

## Progress Update

```
Status: [onTrack|atRisk|offTrack]
Summary: 1 sentence. Completed: [items]. Blocked: [items+owners]. Next: [items].
```

## Tips

- One owner per initiative. Shared ownership = no ownership.
- Target date = hard deadline. Use milestones for intermediate dates.
- Link projects → initiatives for auto-rollup.
- Update weekly. Stale = invisible.
