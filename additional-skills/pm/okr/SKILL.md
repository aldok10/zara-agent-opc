# OKR Skill

## Scope

Draft, review, align, track, and score OKRs. Quarterly planning through retrospective.

## Core Principles

1. Objectives = inspiring, qualitative, directional. No metrics in objectives.
2. Key Results = measurable outcomes, not tasks. Externally verifiable.
3. 3-5 KRs per Objective max. Fewer = sharper focus.
4. 60-70% achievement = well-calibrated for aspirational OKRs. Committed OKRs must hit 1.0 (100%).
5. Weekly check-ins on KR progress (significantly improves completion rates). Not quarterly surprise.
6. Alignment: ~60% bottom-up, ~40% top-down direction. Teams choose HOW, leadership sets WHERE.
7. Each KR owned by exactly one person. Shared ownership = no ownership.
8. Quarterly cadence + mid-quarter review for adjustment.
9. Separate committed (must-hit) vs aspirational (stretch) KRs.
10. Grade honestly: 0.0-1.0 scale. No inflation. 1.0 = set bar too low.
11. Mix leading (input) + lagging (output) indicators across KR set.
12. CFR (Conversations, Feedback, Recognition) is the companion to OKRs for continuous performance management, replacing annual reviews.

## DO NOT

1. Use tasks/activities as Key Results ("Launch feature X" is not a KR)
2. Set more than 5 KRs per Objective or more than 3 Objectives per team
3. Copy company KRs verbatim to team level (cascade = translate, not clone)
4. Score without data. Every KR needs a measurement source defined upfront.
5. Use OKRs as basis for compensation. Doerr: "Divorce compensation (both raises and bonuses) from OKRs. These should be two distinct conversations, with their own cadences and calendars."

## Decision Matrix

| Situation | Action |
|-----------|--------|
| KR is binary (done/not done) | Rewrite as measurable spectrum |
| KR has no baseline | Spend first 2 weeks establishing baseline |
| Objective sounds like a task | Reframe: what outcome does the task serve? |
| Team can't connect to company OKR | Flag misalignment, escalate to leadership |
| Mid-quarter KR clearly wrong | Adjust with documented rationale, don't abandon |
| All KRs at 1.0 | Challenge calibration: goals weren't stretchy enough |

## Verification Criteria

- Every Objective is qualitative, inspiring, time-bound to quarter
- Every KR has: metric, baseline, target, owner, measurement source
- KR set has mix of committed + aspirational
- Alignment map shows clear connection company > team > individual
- Check-in cadence defined before quarter starts
- Scoring uses data, not vibes

## AI-Era Context (2026)

AI helps generate Key Result options from Objectives -- given an objective, it produces candidate KRs with suggested metrics and baselines. The risk: vanity metrics. AI optimizes for measurability over meaningfulness, producing KRs that are easy to track but disconnected from actual outcomes. Human validates that each KR is genuinely measurable, outcome-oriented (not output-oriented), and within team influence. AI also drafts check-in summaries and progress narratives, but scoring decisions remain human-owned.
