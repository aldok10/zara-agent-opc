# Scoring OKRs

## Scale: 0.0 - 1.0

| Score | Aspirational KR | Committed KR |
|-------|-----------------|--------------|
| 0.0 | No progress | Failed to deliver |
| 0.3 | Minimal progress | Significantly missed |
| 0.5 | Halfway, some learning | Below expectations |
| 0.7 | Strong result, target zone | Met expectations |
| 1.0 | Fully achieved (bar too low?) | Exceeded (great or sandbagged?) |

## Interpretation

- **Aspirational KRs**: 0.6-0.7 avg = well-calibrated. Consistent 1.0 = not stretching.
- **Committed KRs**: expect 1.0. Below 0.7 = planning or execution failure.
- **Team average**: 0.6-0.7 across all KRs = healthy. <0.4 = wrong goals or execution crisis.

## Google Grading Colors (Aspirational OKRs)

| Score | Color | Meaning |
|-------|-------|---------|
| 0.7-1.0 | Green | On track |
| 0.4-0.6 | Yellow | At risk |
| 0.0-0.3 | Red | Off track |

## Committed vs Aspirational: Key Distinction

- **Committed OKRs**: pass/fail at 1.0. Missing a committed OKR is "a big deal" (Google OKR Playbook). Requires post-mortem.
- **Aspirational OKRs**: expected to carry over cycle to cycle. 0.7 is strong delivery.

## Scoring Formula

For metric-based KRs:
```
Score = (Actual - Baseline) / (Target - Baseline)
Cap at 1.0. Floor at 0.0.
```

Example: Baseline=100, Target=200, Actual=160 -> Score = 60/100 = 0.6

## Calibration Session Format (60min)

1. **Individual scoring** (10min): each KR owner scores their KRs with data
2. **Team review** (30min): present scores, challenge where data unclear
3. **Calibration** (15min): are we grading consistently? Compare similar KRs.
4. **Retro** (5min): what to carry forward, what to change in process

## Retrospective Questions

Per KR:
- Was the target well-calibrated? (too easy / too hard / just right)
- Did we have the right measurement source?
- What would we do differently?

Per Objective:
- Did achieving KRs actually move the Objective? (outcome validity)
- Were we working on the right things?

## Committed vs Aspirational Scoring

| Type | Expected Score | Miss Means |
|------|---------------|------------|
| Committed | 1.0 | Resource/planning failure. Post-mortem needed. |
| Aspirational | 0.6-0.7 | Healthy stretch. Document learnings. |

## Scoring Pitfalls

- Inflating scores without data ("felt like we did well")
- Scoring tasks-completed not outcome-achieved
- Ignoring KRs that became irrelevant (score 0.0 + note "deprioritized")
- Gaming: changing target retroactively to improve score
- Not distinguishing committed vs aspirational in team averages
