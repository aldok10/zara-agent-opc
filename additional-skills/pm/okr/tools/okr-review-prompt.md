# OKR Quarterly Review Prompt

## Pre-Review (async, before meeting)
Each KR owner fills: actual result, data source, score (0.0-1.0), one-line reason.

## Review Facilitation Flow

### 1. Score Each KR (5 min per Objective)
- Read KR → state target vs actual → assign score
- Committed KRs: 1.0 or 0.0 (binary). Aspirational: use 0.0-1.0 scale.
- Challenge: "What data proves this score? No data = no score."

### 2. Discuss Why (10 min per Objective)
- For hits (≥0.7): "What worked? Is it repeatable or lucky?"
- For misses (<0.5): "Root cause? Was it goal design, execution cadence, or external?"
- For surprises: "What did we learn that changes our assumptions?"

### 3. Extract Lessons (10 min total)
- "What do we STOP doing next quarter?"
- "What do we CONTINUE that's working?"
- "What do we START based on this quarter's learnings?"
- "Which assumptions were proven wrong?"

### 4. Set Next Quarter Themes (10 min)
- Based on lessons, what 2-3 themes should next quarter's OKRs address?
- Carry-forward: any KRs that deserve another quarter (with adjusted targets)?
- Kill: any objectives no longer relevant given new evidence?

## Output: scored KRs + lessons doc + draft themes for next quarter.
