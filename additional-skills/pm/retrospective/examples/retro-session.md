# Example: Full 60-min Retro (Sailboat Format)

## Setup
- Team: 6 engineers + 1 PM, 2-week sprint
- Previous format: Start/Stop/Continue (2x) → rotation triggered
- Tool: Miro board with Sailboat template

## Agenda

| Time | Activity |
|------|----------|
| 0-2min | Safety check (anonymous poll) → score: 4.1 |
| 2-7min | Review previous actions (2/3 done, 1 in progress) |
| 7-8min | Explain Sailboat format |
| 8-13min | Silent write: Wind, Anchor, Rocks, Island |
| 13-18min | Group similar stickies, read themes aloud |
| 18-21min | Dot vote (4 dots each) |
| 21-36min | Discuss top 3 themes (5min each) |
| 36-46min | Discuss themes 4-5 if time (5min each) |
| 46-55min | Form action items |
| 55-60min | Read back actions, appreciation round |

## Example Board Items

**Wind (helps us)**: CI pipeline fast, pair programming Tuesdays, clear sprint goals
**Anchor (slows us)**: flaky test suite, unclear PR review expectations, too many meetings
**Rocks (risks ahead)**: tech debt in auth module, key person dependency on Sara
**Island (goals)**: ship v2.1 on time, reduce bug rate by 30%
