# Facilitation Tips

## Core Techniques

### Silent Writing (5min)
- Everyone writes independently before any discussion
- Prevents anchoring to first speaker
- Gives introverts equal contribution time
- Rule: no talking, no peeking until timer ends

### Dot Voting (3min)
- Each person gets 3-5 dots (votes)
- Can stack on one item or spread
- Reveals true priorities without debate
- Use for: picking discussion topics, prioritizing actions

### Timeboxing
- Set visible timer for each section
- Announce "2 minutes left" warning
- When time's up: "Let's capture this and move on"
- Prevents rabbit holes, ensures coverage

### Parking Lot
- Off-topic but valid items go to "parking lot" board
- Review at end: assign owner or schedule separately
- Prevents derailing without dismissing

### Equal Turn / Round-Robin
- Go around circle: each person speaks once before anyone speaks twice
- "Pass" is always an option
- Use when: quiet people not contributing, dominant voices taking over

### De-escalation
- Redirect blame: "What in our process allowed this?" not "Who did this?"
- Acknowledge emotion: "I hear frustration. Let's capture that."
- Separate observation from judgment
- If heated: 2min silent break, then resume

### Energy Management
- Check energy at start — adjust timebox if low
- Break at 30min mark for 60min+ retros
- Energizer if group is flat (see facilitation-formats.md)
- End 5min early rather than dragging over time

## Facilitator Checklist

- [ ] Prepared board/materials before session
- [ ] Stated format and timebox at start
- [ ] Ran safety check
- [ ] Enforced silent write (no early discussion)
- [ ] Used dot voting (not "what do we think?")
- [ ] Called on quiet participants gently
- [ ] Redirected blame to systems
- [ ] Kept to timebox
- [ ] Confirmed action owners verbally
- [ ] Ended with appreciation/wins

## Remote/Hybrid Best Practices

- **Rhythm**: alternate individual (5min) → small group breakout (10min) → whole group (15min)
- Rotate every 10-15min to prevent Zoom fatigue
- Camera-optional BUT engagement-mandatory (reactions, chat, polls)
- Use breakout rooms for silent write + pair discussion before plenary
- Designated "chat watcher" surfaces async input to facilitator

## AI-Assisted Facilitation

- Use AI to synthesize/cluster retro items (group 30+ stickies into themes)
- AI-generated action item drafts from discussion notes (human approves)
- Sentiment analysis on retro trends across sprints (Retrium, Parabol)
- Never let AI replace human facilitation—augment only

## Equal Participation Techniques

- Anonymous submission (reduces power dynamics)
- Round-robin + "pass" option (ensures air time)
- Written-first always (silent write is non-negotiable)
- Track speaking time—redistribute if >40% from one person
- Explicitly invite quieter members: "X, anything to add?"

## Common Mistakes

- Facilitator gives opinions → stay neutral, ask questions only
- Skipping silent write "to save time" → guarantees groupthink
- No timebox → one topic eats entire session
- Not checking previous actions → signals actions don't matter
- Solving problems in retro → retro identifies, action items solve
