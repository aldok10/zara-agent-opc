# Remote Retros

## Two-Phase Structure

### Phase 1: Async Pre-Write (24h before sync)
- Open board in Miro/FigJam/EasyRetro 24h before meeting
- Everyone adds items independently (no peeking at others until sync)
- Facilitator sends reminder at 24h and 4h marks
- Dot voting opens 2h before sync (async votes allowed)

### Phase 2: Sync Discussion (45min max)
- Skip silent write (done async) — go straight to grouped themes
- Discuss top 3-5 voted items only
- Action items formed live with owner confirmation
- Record session or post summary within 1h

## Timebox (45min sync)

| Phase | Time |
|-------|------|
| Previous actions review | 5min |
| Reveal top-voted themes | 5min |
| Discuss theme 1 | 10min |
| Discuss theme 2 | 10min |
| Discuss theme 3 | 8min |
| Action items + close | 7min |

## Timezone Fairness

- Rotate meeting time if team spans >4h difference
- Track who gets "bad time" — distribute fairly over quarter
- If impossible: extend async phase, shorten sync to 30min
- Record sync for those who can't attend live

## Engagement Techniques

- Anonymous input: use tool's anonymous mode for sensitive topics
- Reaction stamps: encourage emoji/reaction during discussion
- Round-robin: explicitly call on each person for theme discussion
- Chat channel: parallel text for those uncomfortable speaking up
- Small breakouts: 2-3 person rooms for 5min, then regroup

## Tool Recommendations

| Tool | Best For | Notes |
|------|----------|-------|
| Miro/FigJam | Visual teams, Sailboat/Timeline | Async + sync |
| EasyRetro/Retrium | Simple formats, voting built-in | Low friction |
| Notion/Confluence | Teams already in docs ecosystem | Action tracking integrated |
| Slack thread | Micro-retros, <5 people | Lightweight |

## Anti-Patterns

- Only sync, no pre-write → dominant voices win
- No engagement tools → 2 people talk, rest mute
- Camera-mandatory → drains energy, excludes some
- No async option → timezone-disadvantaged miss out
- Reading items aloud without grouping → wastes sync time

## Camera Policy

- Cameras encouraged, never mandatory
- Facilitator has camera on (modeling)
- "Cameras off" normalized for listening phases
- Energy dips: suggest camera break midway

## Verification

- [ ] Async board opened 24h before
- [ ] All team members contributed (check board)
- [ ] Sync focused on top-voted only
- [ ] Timezone rotation tracked
- [ ] Actions confirmed live by owners
