# Quarterly Review

## Purpose

Evaluate bets, re-prioritize based on evidence, align on next quarter. Living roadmap, not annual planning theater.

## Meeting Structure (90 min)

| Block | Duration | Activity |
|-------|----------|----------|
| Results Review | 25 min | Score last quarter's bets against metrics |
| Learnings | 15 min | What surprised us? What invalidated assumptions? |
| Re-prioritize | 25 min | Move items between Now/Next/Later based on evidence |
| Capacity Check | 10 min | Does Now fit actual bandwidth? |
| Next Quarter Plan | 15 min | Commit Now, shape Next, signal Later |

## Pre-work (due 3 days before)

- [ ] PM: Score each Now item (hit/miss/partial + data)
- [ ] PM: Draft proposed column changes with rationale
- [ ] Eng: Capacity estimate for next quarter
- [ ] Design: Discovery findings ready to present
- [ ] All: Flag items to kill, escalate, or add

## Scoring Last Quarter

For each Now item from last quarter:

```
Initiative: [name]
Outcome hypothesis: [what we expected]
Result: HIT / PARTIAL / MISS
Evidence: [metric actual vs target]
Learning: [what we now know]
Action: CONTINUE / ITERATE / KILL / GRADUATE
```

## Re-prioritization Process

1. Kill: items that hit kill criteria or lost strategic relevance
2. Graduate: items that achieved outcome  -  move to maintenance
3. Shift: Later→Next (validated), Next→Now (ready), Now→Next (blocked)
4. Add: new items from discovery, strategy shifts, market changes
5. Validate: does updated Now column fit capacity?

## Output Template

```
## Q[X] Roadmap Review Output

### Results (last quarter)
- [Initiative]: [HIT/MISS]  -  [1-line evidence]

### Killed
- [Item]: [reason]  -  [learning captured]

### Column Changes
- [Item] moved [from → to]: [rationale]

### Next Quarter Now (committed)
- [Initiative]: [owner]  -  [outcome target]

### Next Quarter Next (shaped)
- [Initiative]: [open questions remaining]

### Risks & Dependencies
- [Risk]: [mitigation]
```

## Stakeholder Announcement

After review, publish:
- Executive: updated 1-pager (outcomes + confidence shift)
- Team: updated board with new assignments
- Customer: updated portal if direction changed

## Cadence

- Full review: quarterly (this document)
- Shift check: monthly (15 min  -  anything need to move?)
- Health check: weekly (Now items on track?)

## Anti-patterns

- No scoring → no learning, repeating mistakes
- Review without data → opinions dominate
- Too many items in Now post-review → didn't trim, capacity fiction
- No kills → zombie items accumulate, bandwidth leak
- Skip announcement → stakeholders surprised, trust erodes
