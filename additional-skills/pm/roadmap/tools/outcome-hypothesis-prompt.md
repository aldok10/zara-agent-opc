# Outcome Hypothesis Prompt

## Template

For each roadmap item, write a testable hypothesis:

```
If we build [INITIATIVE],
we expect [METRIC] to move from [BASELINE] to [TARGET]
within [TIMEFRAME].

Evidence supporting this bet:
- [data point / research / signal]

Leading indicators (check before timeframe ends):
- [early signal 1]
- [early signal 2]

Kill criteria: If [metric] doesn't reach [threshold] by [midpoint], reconsider.
```

## Usage

1. Fill one hypothesis per roadmap item before committing to build
2. Baseline must be current measured value (not guessed)
3. Target must be specific number, not "improve" or "increase"
4. Timeframe = realistic measurement window post-launch (not build time)
5. Review hypotheses monthly  -  update or kill items that fail leading indicators

## Quality Check

- Is the metric directly influenced by this initiative?
- Can we measure baseline TODAY?
- Would the team agree this target is ambitious but achievable?
- Are there confounding factors that could explain movement?
