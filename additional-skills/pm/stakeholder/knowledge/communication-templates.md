# Communication Templates

## Weekly Update

```
Subject: [Team] Weekly - [Date] - [Overall RAG]

HIGHLIGHTS: [1-2 wins]
[Initiative 1]: [RAG] - shipped X / next Y / risk Z
[Initiative 2]: [RAG] - shipped X / next Y / risk Z
BLOCKERS: [list or "none"]
ASKS: [decisions needed + deadline]
```

## Escalation Request

```
Subject: [ESCALATION] [Issue] - Decision needed by [date]

SITUATION: [what happened, 2 sentences max]
IMPACT: [quantified: users/revenue/days affected]
OPTIONS:
  A) [option] - [trade-off]
  B) [option] - [trade-off]
RECOMMENDATION: [pick + why]
ASK: Approve by [date] or [consequence]
```

## Decision Record

```
DECISION: [what was decided]
DATE: [when]
DECIDER: [who]
CONTEXT: [why this came up, 2-3 sentences]
OPTIONS CONSIDERED: [brief list]
RATIONALE: [why this option won]
TRADE-OFFS: [what we gave up]
REVIEW DATE: [when to revisit, if applicable]
```

## Meeting Notes

```
MEETING: [title] - [date]
ATTENDEES: [names]
DECISIONS:
- [decision 1]
- [decision 2]
ACTION ITEMS:
- [owner]: [task] by [date]
- [owner]: [task] by [date]
PARKING LOT: [deferred items]
NEXT MEETING: [date/time]
```

## Stakeholder Map Entry

```
NAME: [person]
ROLE: [title]
POWER/INTEREST: [H/H, H/L, L/H, L/L]
CARES ABOUT: [their priorities]
COMMUNICATION: [preferred channel + cadence]
RELATIONSHIP: [champion/neutral/blocker]
STRATEGY: [how to engage]
```

## Async Status Update (replaces status meetings)

Cadence: biweekly. Reading time: <5 minutes.

```
Subject: [Team] Update - [Date range]

HEADLINE: [1 sentence  -  most important thing to know]

SHIPPED:
- [item]: [impact/metric if available]

BLOCKED:
- [item]: [who/what is needed]

NEED FROM YOU: [specific asks with deadlines]

NEXT 2 WEEKS: [top 2-3 priorities]
```

## Data Storytelling Structure

For presenting insights to stakeholders who need to act:

```
CONTEXT: [why this matters now, 1-2 sentences]
INSIGHT: [what the data shows, with key numbers]
RECOMMENDATION: [what we should do]
ASK: [specific action + timeline]
```

**Tips**: Lead with "so what", not methodology. One insight per message. Attach detail as appendix, don't inline it.
