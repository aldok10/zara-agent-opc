# Executive Communication

## Scope

Communicate up to leadership. Frame outcomes, not activities. Drive decisions.

## Framework: Minto Pyramid

1. **Conclusion first** - state the answer/recommendation
2. **Supporting arguments** - 2-3 key reasons
3. **Data/evidence** - proof points underneath

Never: bottom-up narrative, chronological storytelling, data-first dumps.

## Formats

### Decision Request
```
DECISION NEEDED: [one sentence]
IMPACT: [what happens if delayed/wrong]
OPTIONS:
  A) [option] - pros / cons / effort
  B) [option] - pros / cons / effort
RECOMMENDATION: [A/B] because [reason]
DEADLINE: [date needed by]
```

### Executive Summary
```
STATUS: [RAG]
OUTCOME: [what we achieved/targeting]
KEY METRIC: [number that matters]
ASK: [what you need from them]
```

### Progress Update (exec-level)
```
[Initiative]: [RAG] - [one sentence outcome]
SHIPPED: [impact, not task list]
NEXT: [milestone, not activities]
RISK: [if any, with mitigation]
```

## Rules

- Lead with "so what" not "what happened"
- One page max. If longer, attach appendix
- Quantify impact: revenue, users, days, cost
- State confidence level on estimates
- Prep the 3 questions they'll ask

## Anti-patterns

- Burying the ask in paragraph 4
- Data dump without interpretation
- Technical jargon without business translation
- Presenting problems without options
- Waiting for meeting to surface urgent news
- No recommendation (forcing exec to do your job)

## When to Use

- Board/exec updates
- Budget/headcount requests
- Strategic decisions needing approval
- Quarterly business reviews
- Incident post-mortems to leadership

## Verification

- Conclusion appears in first sentence
- Ask is explicit and actionable
- Impact quantified where possible
- Options presented with recommendation
- Fits on one page/screen
