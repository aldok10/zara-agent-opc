# Executive Brief Prompt

## Structure (Minto Pyramid — conclusion first)

```
DECISION REQUESTED: [what you need approved/decided, 1 sentence]

RECOMMENDATION: [your position, 1-2 sentences]

IMPACT: [quantified: revenue, users, timeline, risk]

CONTEXT (only what's needed to decide):
- [key fact 1]
- [key fact 2]
- [key fact 3]

OPTIONS:
A) [recommended] — [pro] / [con]
B) [alternative] — [pro] / [con]
C) Do nothing — [consequence]

NEXT STEPS (if approved):
- [action 1] by [date]
- [action 2] by [date]
```

## Rules

- Total length: <1 page / <5 min reading time
- Lead with what you need, not background
- Quantify impact in exec-relevant terms (revenue, headcount, timeline)
- Max 3 options. Include "do nothing" with stated cost
- No jargon. If a term needs definition, use a different word
- Attach supporting data as appendix, never inline
