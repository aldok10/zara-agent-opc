# Quarterly Team Health Check Prompt

## Agenda (60 min)

### 1. DORA Metrics Review (15 min)
```
Pull last quarter's numbers:
- Deploy frequency: [X] → trend: [up/down/flat]
- Lead time: [X] → trend
- Change failure rate: [X%] → trend
- Recovery time: [X] → trend
- Rework rate: [X%] → trend (NEW)

Flag: Any metric degraded >20% from prior quarter? Root cause?
AI-specific: CFR for AI-assisted vs human-written changes?
```

### 2. DevEx Survey Results (15 min)
```
Scores by dimension (1-5):
- Flow State: [avg] (delta from last Q)
- Cognitive Load: [avg]
- Feedback Loops: [avg]
- AI Tool Satisfaction: [avg] (NEW)
- BICEPS dimensions: [flag any <3.5]

Top concern from open responses: [theme]
```

### 3. Cognitive Load Assessment (15 min)
```
- Team scope expanded? New services/ownership?
- Toil ratio: what % of sprint is unplanned/maintenance?
- AI-generated code adding review burden?
- Platform/tooling gaps causing friction?
```

### 4. Action Planning (15 min)
```
Last quarter's actions: [completed / in-progress / dropped]
This quarter  -  pick max 2:
1. [action]  -  owner: [who]  -  success metric: [what]
2. [action]  -  owner: [who]  -  success metric: [what]
```
