# D2 Diagrams

D2 language syntax, layouts, themes, imports, and animations for declarative diagrams.

## When to Load

- Creating complex diagrams that exceed Mermaid's capabilities
- Needing custom layouts (ELK, TALA, dagre)
- Building multi-file diagram systems with imports
- Wanting more visual control over diagram appearance

## Key Concepts

**Syntax** -- Declarative diagram language. Connections: `a -> b`, labels: `a -> b: label`, containers: `group { a; b }`. Shapes via `shape:` property. More expressive than Mermaid for complex layouts.

**Layouts** -- Pluggable layout engines. dagre (default, fast), ELK (best for complex graphs), TALA (proprietary, highest quality). Set via `direction` and `--layout` flag.

**Themes** -- Built-in: default, dark, ocean, grape, vanilla. Custom via `vars` block for colors, fonts, borders. Consistent styling across diagrams.

**Imports** -- Split diagrams across files with `...@file.d2`. Enables reusable components, shared styles, and modular architecture diagrams. Supports glob imports.

**Animations** -- Step-based animations via `steps` key. Each step shows/hides elements. Useful for explaining sequences or build-up diagrams in presentations.

## Patterns

```d2
# Basic architecture diagram
direction: right

client: Client {
  shape: person
}

gateway: API Gateway {
  shape: hexagon
}

services: {
  auth: Auth Service
  orders: Order Service
  notify: Notification Service
}

db: PostgreSQL {
  shape: cylinder
}

client -> gateway: HTTPS
gateway -> services.auth: validate
gateway -> services.orders: forward
services.orders -> db: query
services.orders -> services.notify: event
```

```d2
# Themed with custom vars
vars: {
  d2-config: {
    theme-id: 200
    layout-engine: elk
  }
}

# Container with internal connections
backend: Backend {
  api: REST API
  worker: Background Worker
  cache: Redis {
    shape: cylinder
    style.fill: "#ff6b6b"
  }
  api -> cache: read-through
  api -> worker: enqueue
}
```

```d2
# Multi-file with imports
# main.d2
...@./shared/styles.d2
...@./components/auth.d2
...@./components/data.d2

auth -> data.db: query
```

```d2
# Animation steps
steps: {
  1: {
    client -> gateway: "1. Request"
  }
  2: {
    gateway -> service: "2. Validate & Forward"
  }
  3: {
    service -> db: "3. Persist"
  }
  4: {
    service -> client: "4. Response"
  }
}
```

## Gotchas

- TALA layout engine requires a commercial license -- dagre and ELK are free
- Import paths are relative to the file, not the project root
- Animations only work in SVG output (not PNG) and require a compatible viewer
- D2 is less widely supported than Mermaid -- no native GitHub/GitLab rendering
- Container nesting beyond 3 levels makes diagrams hard to read regardless of tool

## Verification

- Compile with `d2 --watch` during authoring for live preview
- Test with target layout engine (output differs significantly between dagre and ELK)
- Verify imports resolve correctly: `d2 fmt` catches broken references
- Check SVG output renders in target browser for animated diagrams
- Ensure diagram fits within reasonable viewport without scrolling
