# Evaluator Rubric

Score after implementation, before acceptance. Each dimension is 0-2.

| Dimension | Question | Score | Notes |
|---|---|---|---|
| Correctness | Does the behavior match the contract? | | |
| Verification | Did the required commands run, with recorded evidence? | | |
| Scope discipline | Did the session stay inside the contract? | | |
| Reliability | Does it survive a rerun or a fresh session? | | |
| Maintainability | Can the next session read and change it? | | |
| Handoff readiness | Can work continue from tracked files only? | | |

## Grade

- A: 10-12, no dimension below 2.
- B: 7-9, no dimension below 1.
- C: 4-6, at least one dimension at 0.
- D: 0-3.

## Verdict

- Accept (B or above)
- Revise (C)
- Block (D)
